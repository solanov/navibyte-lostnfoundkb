
# Fullstack Developer - Peja A. Escares

Developing the Navibyte Lost & Found system was a comprehensive exercise in full-stack software engineering, bridging the gap between a conceptual idea and a production-ready application. Building the platform utilizing Next.js, TypeScript, and Supabase provided a robust, modern technology stack that allowed for scalable architecture and rapid feature development. By leveraging the Next.js App Router and server actions, I was able to create a seamless, server-side rendered experience that handled data fetching securely and efficiently. Integrating Supabase as the Backend-as-a-Service (BaaS) was instrumental in managing complex user authentication, role-based access control, and the real-time database requirements necessary for features like the in-app messaging system. This stack not only accelerated the development process but also deepened my understanding of how modern React ecosystems interact with backend services.

A significant portion of my learning came from managing the complex business logic and user flows inherent to a lost-and-found system. Implementing the dual-interface architecture—a public-facing board for users to report and claim items, alongside a secure, comprehensive admin dashboard for moderation, user management, and audit trails—required careful state management and security considerations. Developing the claims process and the peer-to-peer messaging features challenged me to think critically about data privacy, ensuring that users could securely communicate and verify ownership without exposing sensitive personal information. Furthermore, designing a responsive and intuitive user interface with custom components, from dynamic status badges to complex modal overlays and multi-platform navigation bars, significantly refined my frontend development skills and focus on user experience.

Beyond writing code, this project emphasized the critical importance of disciplined software engineering practices. Maintaining comprehensive documentation, including Architecture Decision Records (ADRs), prompt logs, and weekly standup notes, transformed the development process from a solitary coding task into a professional, structured project. Designing wireframes, writing extensive test cases for authentication and CRUD operations, and logging architectural decisions ensured that the project remained focused and maintainable as its complexity grew. Ultimately, this experience was invaluable; it not only solidified my technical proficiency with modern web frameworks but also taught me how to approach software development as a holistic engineering discipline, balancing clean code with rigorous planning and user-centric design.
