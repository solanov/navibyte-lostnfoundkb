# Put the UI Pages Prototype here
 
### Each page should be in a separate folder with a snippet of actual page that came from stitch

## Procedures:

1. Download the page in stitch
2. Save it as html file / .zip 
3. Upload the extracted folder here
4. Rename the folder according to the pages
